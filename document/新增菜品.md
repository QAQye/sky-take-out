第一步：浏览器选择文件

比如进入系统，点击「上传文件」，选择了一张 `avatar.jpg`。

第二步：浏览器把文件发送给 Java 后端

前端通过 HTTP 请求上传文件，例如：

```
POST /upload
Content-Type: multipart/form-data
```

后端 Spring Boot 通过 `MultipartFile` 接收文件。

第三步：Java 后端调用阿里云 OSS 接口

后端拿到文件后，调用阿里云提供的 SDK，把文件上传到 OSS。

这一步才是真正使用了 OSS 的上传接口。

第四步：OSS 保存文件并返回结果

阿里云 OSS 保存文件后，Java 后端可以生成文件的访问地址或对象标识，再返回给前端。

```
{
  "code": 1,
  "data": "https://example.oss-cn-chongqing.aliyuncs.com/avatar.jpg"
}
```

### 阿里云OSS服务接口

OSS 的英文全称是 Object Storage Service（对象存储服务），中文叫对象存储。
为什么不直接使用mysql直接存储呢，是因为这样做可以数据库不用承担大量图片或视频文件的存储负担，文件也更容易独立管理和扩展。

例如 MySQL 学生表：

```
student
----------------------------------
id      1001
name    张三
avatar  students/1001/avatar.jpg
```

OSS 中则保存真正的头像文件：

```
campus-bucket
   └── students
        └── 1001
             └── avatar.jpg
```

阿里云提供的一套 API，让 Java 程序能够操作阿里云中的文件。

例如：

| OSS 操作     | 功能                             |
| ------------ | -------------------------------- |
| 上传文件     | 将图片、PDF 上传到 OSS           |
| 下载文件     | 将 OSS 中的文件下载回来          |
| 删除文件     | 删除 OSS 中不再需要的文件        |
| 查询文件     | 获取文件信息                     |
| 生成签名 URL | 允许用户在规定时间内访问私有文件 |

Java 开发中，通常不需要自己构造复杂的 HTTP 请求，可以直接使用阿里云提供的 OSS Java SDK。

```
// 创建 OSS 客户端（前提是已配置 endpoint 和凭证）
OSS ossClient = new OSSClientBuilder().build(
    endpoint, accessKeyId, accessKeySecret
);

// 上传文件
ossClient.putObject(
    "campus-bucket",   // Bucket 名称
    "avatar.jpg",      // OSS 文件对象名
    inputStream        // 文件输入流
);

// 关闭客户端
ossClient.shutdown();
```

这段代码最关键的是：

```
ossClient.putObject(...)
```

它的意思就是：

让 Java 程序把指定文件上传到阿里云 OSS。其中几个关键的概念：

Bucket（存储桶）：相当于一个存放文件的大仓库。

Object（对象）：OSS 中存放的具体文件，例如 `student/avatar.jpg`。

Endpoint（服务访问地址）：你的 Java 后端连接某个区域 OSS 服务所使用的地址。

### 依赖注入的方式

依赖注入的两种方式

1.一种是通过普通的@value方式来进行注入

假设 `application.yml` 中有：

```
sky:
  alioss:
    endpoint: oss-cn-chongqing.aliyuncs.com
    access-key-id: xxx
    access-key-secret: xxx
    bucket-name: campus
```

使用 `@Value` 获取配置

```
@Component
@Data
public class AliOssProperties {

    @Value("${sky.alioss.endpoint}")
    private String endpoint;

    @Value("${sky.alioss.access-key-id}")
    private String accessKeyId;

    @Value("${sky.alioss.access-key-secret}")
    private String accessKeySecret;

    @Value("${sky.alioss.bucket-name}")
    private String bucketName;
}
```

```
@Component
```

将 `AliOssProperties` 类交给 Spring 容器管理，使 Spring 能够创建对象并处理字段上的注解。

```
@Value
```

读取指定的配置项，然后注入对应的字段。

例如：

```
@Value("${sky.alioss.endpoint}")
private String endpoint;
```

意思是：

从 Spring 配置环境中读取 `sky.alioss.endpoint` 的值，然后赋给 `endpoint` 属性。

2.使用 `@ConfigurationProperties`

这是在苍穹外卖项目中使用的方式。

YAML 配置文件

```
sky:
  alioss:
    endpoint: oss-cn-chongqing.aliyuncs.com
    access-key-id: xxx
    access-key-secret: xxx
    bucket-name: campus
```

创建配置属性类

```
@Component
@ConfigurationProperties(prefix = "sky.alioss")
@Data
public class AliOssProperties {

    private String endpoint;

    private String accessKeyId;

    private String accessKeySecret;

    private String bucketName;
}
```

这里的核心是：

```
@ConfigurationProperties(prefix = "sky.alioss")
```

意思是：

将配置文件中所有以 `sky.alioss` 开头的配置项，按照属性名称绑定到 Java 对象中。

意思是：

将配置文件中所有以 `sky.alioss` 开头的配置项，按照属性名称绑定到 Java 对象中。

例如：

```
sky.alioss.endpoint
        ↓
private String endpoint;
sky.alioss.access-key-id
        ↓
private String accessKeyId;
```

其中在这里官方推荐 YAML 或 Properties 文件中采用短横线命名法（kebab-case），例如：

```
access-key-id: xxx
```

Java 字段则采用小驼峰命名法（camelCase）：

```
private String accessKeyId;
```
